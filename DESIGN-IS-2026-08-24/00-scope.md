# W-Link 设计审计范围

- 审计对象：Flutter 应用的主要用户可达界面与通用交互组件。
- 主要用户：在同一局域网内管理一个或多个 WLED 灯具的移动端用户。
- 主要任务：快速找到设备，并以最少步骤控制开关、亮度、颜色、效果和预设。
- 次要任务：发现设备、管理分段/分组/Nightlight、调整应用设置。
- 技术约束：Flutter、Riverpod、WLED JSON API、HTTP + WebSocket、移动端优先并兼容宽屏。
- 品牌约束：W-Link / 幻彩；紫色主品牌、深夜玻璃态、设备色作为环境光。
- 审计材料：静态源码、主题 token、组件结构、现有自动化测试。未连接真实 WLED，未进行实体设备性能和屏幕阅读器测试。
- 竞争参照：WLED 官方 Web UI 与通用智能灯控制器；本轮不做外部竞品联网研究。
