# 帮助与支持 (Help & Support)

感谢您选择并使用 **W-Link**。如果您在使用过程中遇到任何问题，或者对应用有任何功能建议，欢迎随时查阅本指南或联系我们。

## 常见问题解答 (FAQ)

### Q: 为什么应用搜索不到我的 WLED 设备？
A: 自动发现功能依赖于 mDNS 广播协议。请按照以下步骤排查：
1. **网络一致性**：请确保您的手机和 WLED 设备连接在**同一个 Wi-Fi 局域网**下。
2. **本地网络权限 (重要)**：如果您使用的是 iOS 设备，系统会拦截应用搜索局域网设备。请前往 `iOS 设置 -> 隐私与安全性 -> 本地网络`，或者直接在设置列表中找到 `W-Link`，确保已开启“**本地网络**”权限。
3. **设备状态**：请检查您的 WLED 设备是否已正常通电启动，且已成功连接至家里的路由器。
4. **路由器设置**：部分路由器默认开启了“AP 隔离”或禁用了组播（mDNS）功能，请登录路由器后台确保这些限制已被关闭。

### Q: 应用是否支持离开家后的外网远程控制？
A: **目前不支持**。出于最高级别的安全和隐私考虑，W-Link 设计为一款纯纯本地的控制应用，仅在您的家庭局域网内工作。这样可以确保您的设备不会暴露在公网中被恶意攻击。

### Q: 应用的耗电量大吗？
A: W-Link 经过了严格的性能优化，使用了 Flutter 引擎的高效渲染机制。只有在应用处于前台运行并主动控制灯光时才会进行网络通信，退到后台后会立即挂起，几乎不会消耗电量。

### Q: 是否支持自定义 WLED 设备的 IP 地址？
A: 目前版本主打极简的自动发现体验。如果在复杂网络环境下确实无法自动发现，我们在后续版本中会考虑加入手动添加 IP 的入口。如果您有强烈需求，请在 GitHub 提交建议。

## 获取官方支持与反馈

W-Link 是一个充满活力的开源/半开源项目，我们非常看重社区的反馈。如果您遇到了 Bug，或是希望我们加入某个炫酷的新功能，请通过以下方式与我们取得联系：

👉 **[在 GitHub 提交 Issue 反馈](https://github.com/fkueyu/W-Link/issues)**

提交 Issue 时，请尽量提供以下信息，以便我们更快地定位问题：
- 您的手机型号及系统版本（如 iPhone 14 Pro, iOS 17.0）
- W-Link 的应用版本号
- 您的 WLED 固件版本号（如 v0.14.0）
- 问题发生的具体场景和复现步骤

我们会在收到反馈后的第一时间为您解答！
