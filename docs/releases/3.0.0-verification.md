## 原生macOS边界

常规flutter build macos --release --no-pub失败：
- Flutter传给系统lipo的双架构-verify_arch调用返回“requires exactly one input file”，而lipo -info显示二进制确有x86_64和arm64。单独arm64验证成功；这不是通过删除架构解决的问题。
- 仅本次命令覆盖ARCHS=arm64/ONLY_ACTIVE_ARCH=YES继续探查，Xcode报告工程部署目标10.15低于当前SDK支持范围12.0至27.0.x；该验证仍失败。
- 未修改全局Flutter、工程部署目标、正式包标识或商店身份。
- macOS已有原生Bonjour桥，位置为macos/Runner/AppDelegate.swift；本轮没有Mac设备发现与控制的完整实机验收。
