# W-Link 3.0.0 — App Store 更新文案

版本：3.0.0

构建：15

## 简体中文（版本更新）

- 完善 iPhone Duo 适配，优化内外屏切换、双栏导航与系统工具栏。
- 改进设备发现、网络状态更新和部分 WLED 固件的兼容性。
- 优化调色、预设、分段与定时渐暗操作，改善窄屏和大字号布局。
- 调整卡片柔光、提示留白与文字对比度，提升整体视觉体验。

## English (What's New)

- Improved iPhone Duo support, including screen transitions, two-pane navigation, and system toolbars.
- Improved device discovery, network status updates, and compatibility with some WLED firmware versions.
- Refined color, preset, segment, and sleep timer controls, with better layouts on compact screens and at larger text sizes.
- Polished card lighting, spacing, and text contrast.
