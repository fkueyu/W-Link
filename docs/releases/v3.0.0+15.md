# W-Link 3.0.0

中文 | English

本次发布使用 Flutter 3.47.9 / Dart 3.13.7，保留纯 SwiftPM 集成。发布标签为 `v3.0.0+15`；早期失败构建的 `v3.0.0` 标签保留，不覆盖。

Built with Flutter 3.47.9 / Dart 3.13.7 and SwiftPM. The release tag is `v3.0.0+15`; the earlier failed `v3.0.0` tag remains unchanged.

## 更新内容

- 完善 iPhone Duo 内外屏切换、双栏导航与系统工具栏适配。
- 改进设备发现的取消、超时和错误反馈，恢复前台时及时更新网络状态。
- 兼容部分 WLED 固件的白光能力字段，修复设备信息加载失败。
- 优化调色、预设、分段、定时渐暗及弹层操作，改善窄屏和大字号布局。
- 调整卡片柔光、提示留白、文字对比度与无障碍交互。
- 设置页显示当前安装包的实际版本号。
- 新增 macOS 通用版与 Windows x64 便携包的自动构建和发布，Windows 设置页同步显示实际版本。

## Changes

- Improved iPhone Duo screen transitions, two-pane navigation, and system toolbar support.
- Improved discovery cancellation, timeouts, error feedback, and network status refresh when returning to the app.
- Fixed device information parsing for WLED firmware using boolean white-channel capability values.
- Refined color, preset, segment, sleep timer, and sheet interactions, including compact and large-text layouts.
- Polished card lighting, spacing, text contrast, and accessibility.
- Settings now shows the installed app's actual version.
- Added automatic macOS Universal and Windows x64 builds, including installed-version reporting on Windows.

## 下载 / Downloads

- Android APK：用于直接安装或覆盖更新现有版本。
- Android AAB：用于 Google Play 提交；不能直接安装。
- macOS：W-Link_macos_universal.zip，包含 Apple Silicon 与 Intel 架构，要求 macOS 12.0 或更高版本；当前为未公证构建。
- Windows：W-Link_windows_x64.zip，解压完整目录后运行 W-Link.exe，保留同目录的 data 和 DLL 文件。
- iOS / iPadOS：同一通用包，通过 App Store 分发；未签名归档保存在对应 Actions 的构建产物中，不作为可直接安装的 IPA 发布。
- 本轮不新增 Linux 安装包。
