# W-Link 3.0.0 发布准备 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 将本轮已授权修复发布为3.0.0+15，准备iOS提交资料，并提交/推送代码与v3.0.0标签发布Android更新。

**Architecture:** pubspec.yaml是应用版本唯一来源，iOS/Android/macOS构建读取该值。现有GitHub标签流程负责签名Android AAB/APK；iOS商店提交由用户执行。

**Spec:** 用户本轮要求：版本号提高到3.0.0、准备App Store；评估其他平台，有必要则提交、推送、打tag。

- 远程main必须是本地历史祖先，不强推，不覆盖既有标签。

## Review Focus

- 构建产物的实际版本，不只核对配置文本。
- Android实际签名与versionCode；v3.0.0标签指向已验证代码。

- macOS默认包标识/原生发现能力与正式商店支持区分。
- 远程CI、发布资源成功不能仅以本地构建替代。
