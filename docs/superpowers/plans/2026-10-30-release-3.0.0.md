# W-Link 3.0.0 发布准备 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 将本轮已授权修复发布为3.0.0+15，准备iPhone/iPad提交资料，并提交/推送代码与v3.0.0+15标签发布Android、macOS与Windows更新。

**Architecture:** pubspec.yaml是应用版本唯一来源。标签流程并行验证与构建Android签名AAB/APK、macOS通用ZIP、Windows x64 ZIP和iPhone/iPad未签名归档，全部成功后统一发布Android及桌面下载文件；Apple商店签名/提交由用户执行。用户后续明确要求补齐桌面端，因此替换先前仅发布Android的范围。

**Spec:** 用户本轮要求：版本号提高到3.0.0、准备App Store；评估其他平台，有必要则提交、推送、打tag。

用户追加要求升级全局SDK，因此改用最新stable Flutter3.47.9/Dart3.13.7，保留SwiftPM；macOS按SDK自动迁移到最低12.0。258测试、6项产物校验、独立缓存iOS归档和Mac通用Release在本机通过。

早期v3.0.0标签已触发失败构建，但没有公开Release。为遵守不覆盖既有标签，后续改用v3.0.0+15发布同一应用版本，发布前先验证新SDK的完整全平台预演。
