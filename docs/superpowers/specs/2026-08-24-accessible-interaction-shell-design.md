# W-Link 可访问交互与自适应壳设计

## 目标

在不改变 W-Link 现有极光玻璃视觉的前提下，让自定义弹性按钮具备完整的键盘、焦点和读屏行为，并消除宽屏双栏中重复绘制的全局极光背景。

## 交互基础

`BouncyButton` 继续负责 W-Link 标志性的按压缩放和轻触反馈，但不再只依赖触摸手势。组件统一提供按钮语义、启用状态、可选语义标签、焦点节点和自动聚焦入口；获得键盘焦点后显示品牌紫焦点环，Enter 与 Space 触发与点击相同的主操作。

禁用状态不接受点击、长按或键盘激活，也不触发震动。仅提供长按操作的控件仍保留长按语义，但不会把 Enter/Space 错误映射到不存在的点击操作。指针操作仍使用原有回弹节奏，键盘操作执行一次主操作，不模拟持续按压。

焦点环使用现有品牌紫和紧凑圆角，不引入新字体、颜色体系或第三方组件。组件保留子节点自身的文本与图标语义；调用端可以用 `semanticLabel` 为纯图标按钮补充明确名称。

## 背景所有权

窄屏下 `DeviceListScreen` 仍拥有自己的 `AnimatedBackground`。宽屏下 `AdaptiveShell` 是整块双栏的唯一全局背景所有者；嵌入的 `DeviceListScreen` 使用透明 Scaffold 和原始内容，不再创建第二个 `AnimatedBackground`。

这一规则只移除重复的全局氛围层。设备详情的 `DeviceAmbientBackground` 属于与设备颜色关联的局部状态反馈，仍保留在右栏，避免削弱“当前灯光进入界面”的产品特征。

## 错误与边界

- 组件卸载时释放动画和焦点相关资源，不遗留帧回调。
- `onTap` 与 `onLongPress` 都为空时，按钮以禁用语义呈现且不可聚焦激活。
- 嵌入模式继续由现有 `onDeviceSelected != null` 判断，不新增第二套宽屏状态来源。
- 本阶段不合并 Nightlight、不迁移全部视觉常量，也不改变 WLED 通信方式。

## 验证

- Tab 能把焦点移入弹性按钮，Enter 与 Space 各触发一次点击。
- 禁用按钮不会因指针或键盘操作触发回调。
- 读屏语义包含按钮角色、启用状态和调用端提供的标签。
- 宽屏自适应壳只存在一个 `AnimatedBackground`，窄屏设备列表仍存在一个。
- 原有命令失败 Toast、设备列表和控制页测试继续通过。
