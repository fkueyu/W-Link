# 隐私政策 (Privacy Policy)

**最后更新日期：2023年10月27日**

欢迎使用 W-Link（以下简称“本应用”）。我们深知隐私对您的重要性，并致力于保护您的个人信息安全。本隐私政策旨在向您说明本应用如何收集、使用和保护您的信息。

请仔细阅读本隐私政策。**当您开始使用本应用时，即表示您已阅读、理解并同意本政策的所有条款。**

## 1. 我们如何收集和使用信息

**W-Link 的核心设计理念是“纯本地化运作”，我们采取极简的权限策略，最大限度地保护您的隐私。**

### 1.1 我们不收集的个人信息
- 我们**不**要求您注册账号，因此**不**收集您的姓名、电话号码、电子邮件地址等身份信息。
- 我们**不**收集、**不**存储、**不**上传您的任何设备使用习惯、灯光控制记录或偏好设置到任何外部云端服务器。
- 本应用**不**集成任何第三方的用户行为追踪 SDK 或广告 SDK。

### 1.2 本地处理的数据与权限
为了使应用正常运行并控制您的 WLED 设备，我们需要您授予以下必要权限，但这些数据仅在您的设备本地处理，绝不会离开您的局域网：

- **本地网络权限 (Local Network)**
  **目的**：本应用需要通过 mDNS (多播 DNS) 协议在您的局域网内搜索并发现兼容的 WLED 设备，同时需要通过 HTTP 协议向设备发送控制指令（如颜色、亮度、开关等）。
  **数据去向**：所有的网络通信仅发生在他的手机与您家中的 WLED 设备之间。我们不会获取您的路由器信息，也不会将扫描到的内网 IP 地址发送给任何人。

- **存储权限 (可选)**
  **目的**：仅当您需要保存自定义的灯光配置或导出应用的报错日志时，才会在本地设备中读写文件。

## 2. 数据共享与披露

**我们承诺，我们绝不会向任何第三方公司、组织或个人出售、共享或披露您的任何数据。** 由于我们根本不收集您的数据，因此也没有任何数据可供分享。

## 3. 未成年人保护

本应用不包含任何限制级内容，适合所有年龄段的用户使用。我们不会有意收集任何未满 18 周岁未成年人的个人信息。

## 4. 您的权利

由于 W-Link 所有的数据均存储在您的本地设备上（如本地的 SharedPreferences 缓存），您可以随时通过以下方式行使您的数据控制权：
- 在应用设置中清除应用缓存数据。
- 直接卸载本应用，所有本地相关的应用数据将被系统彻底删除。

## 5. 隐私政策的变更

随着应用功能的迭代或相关法律法规的更新，我们可能会适时对本隐私政策进行修订。当条款发生重大变更时，我们会在应用内显著位置或更新日志中予以提示。如果您继续使用本应用，即表示您同意受修订后的隐私政策约束。
